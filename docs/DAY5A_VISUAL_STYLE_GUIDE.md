# Day 5A 视觉规范：阳光维修桌

更新日期：2026-10-15（Asia/Shanghai）。设计基准为 Cocos Creator 3.8.8 的 720 × 1280 Canvas。

采用明亮、圆润的 2D 扁平卡通设备，加少量侧边厚度、高光和接触阴影。设备插画应先被形状识别，再由中文小标签确认。正式 Creator 装配保存已完成，见 [full-build-report.json](validation/day5a/full-build-report.json)；49 个视觉 key 的实际绑定审计 [643/643](validation/day5a/scene-audit.json)，九单十三步及重玩记录见 [preview-run.json](validation/day5a/preview-run.json)。

## 色板与材质

| 用途 | 色值 | 应用 |
| --- | --- | --- |
| 远景 | `#EAF5F5` | Canvas 背景、首页外围 |
| 桌面 | `#E9CDA7` | 浅木色维修桌，可加稀疏木纹 |
| 工作垫 | `#F8F3E9` | 交互区内层、纸质区域 |
| 主操作 | `#2EAAA8` | 主按钮PNG的基础青绿色、设备外壳局部 |
| 按下 | `#C9EBEB`（tint） | 实际按下态为按钮基础PNG×此tint |
| 主文字/描边 | `#263D50` | 深蓝灰标题、设备轮廓 |
| 次文字 | `#667D8C` | 辅助文字 |
| 成功 | `#49B989` | 对勾、接口状态灯 |
| 错误 | `#E57A78` | 短促局部错误反馈 |
| 奖励 | `#FFBE58` | 星星、设备少量黄铜/塑料点缀 |
| 卡片 | `#FFFFFF` | HUD、结算、首页按钮区 |
| 阴影 | `#526779`，约 12% alpha | 低对比接触阴影 |

至少保留远景、桌面/工作垫、物件三个层次。线条不是纯黑，设备不依赖彩虹填色。CableStyle 六色继续用于线与外圈，实际接头使用不同几何轮廓、针脚和中文标注；色觉受限时仍能匹配。

## 字体与组件尺寸

沿用系统中文无衬线字体，无外部字体依赖。标题 36～42 px，订单名 28～32 px，普通说明 22～26 px，统计 24 px，设备小标签 18～22 px。小标签不得代替设备图。

主 CTA 至少280×84，实际首页按钮390×96。首页音效按钮同时提供图标与开/关文字。HUD、结算和CTA使用真实`ui/card`/`ui/button` SpriteFrame与Sprite.Type.SLICED；192×128源图圆角24 px，borderLeft/borderRight各32，borderTop/borderBottom各38，放大节点时保留角部和阴影边界。卡片仅作装饰；额外透明 Button/BlockInputEvents 不可覆盖玩法。

主按钮状态由青绿基础PNG与tint相乘产生：normal `#FFFFFF`、hover `#EBFFFF`、pressed `#C9EBEB`、disabled `#B6C7C7`，0.08秒过渡。音效次按钮使用白卡PNG与其浅青状态tint。规范色板的主操作颜色描述基础纹理，最终显示颜色同时由纹理和tint决定。

设备 PNG 统一 384 × 256 透明画布，通常放在原 hitbox 上部。三列与两列物品根仍为 180 × 140，四列仍为 140 × 110。建议图像显示 170 × 104 / 132 × 78，下方留给中文标签，不能缩小命中根节点、改变布局坐标或基准缩放。目标复用相同图形，降低饱和度/透明度，外围加浅青描边或虚线槽；形状与源物件必须对应。

线头/接口源图 256 × 128，原 Head/Port 根命中框仍为 130 × 80。头部的输入归属、Anchor、Line、端点计算保持原语义；图标是被输入节点拥有的装饰子节点。线保持动态，完成态只作视觉提示，不额外增加进度。

清洁 InputSurface 维持 **680 × 560**。设备底图放在 DirtLayer 下层，透明污渍位于底图上；污渍视觉可自然重叠，命中格及所需格数仍由原 controller 控制。污渍贴图无实体方格背景。底图与污渍均不可绑定输入拦截器。

## 首页布局草图

坐标为设计意图，真实数值以 Creator 保存结果为准。首页需要独立初始状态，Stage 不加载、计时不运行。

```text
720 × 1280
┌────────────────────────────┐
│      桌面急救站              │  42 px / 深蓝灰
│  修好小设备，收获大满足        │  24 px / 次文字
│                            │
│   原创维修桌插画              │  键盘、鼠标、耳机与工具
│   明确设备轮廓与木色桌面       │  作为装饰，不拦截输入
│                            │
│      [ 开始维修 ]            │  ≥280 × 84 / 高对比
│      [音效图标  音效开]       │  真正的 session 开关
└────────────────────────────┘
```

开始按钮 hover/pressed 有明确变化，快速连点只开始一次。用户首次点击后方可尝试播音，不在首页打开时自动播音。首页关闭后不得留下挡住 Stage 的透明背景。没有继续、商城、广告或金币按钮。

## 游戏与结算

顶部安排章节/订单号、订单标题/步骤、用时/失误，间距服务于可读性。工作台占主视觉，提示气泡在操作区之外；四列物品不扩宽到相邻触摸框。目标在物品下层，接口亮灯与对勾一次出现。

结果卡突出标题、1～3 个真实星形图与得分，随后列用时、失误、步骤数。第 1～8 单主按钮为下一张，第 9 单为重新挑战。九单总结展示 9/9、13/13、累计星级/用时/失误/得分，不能引入未实现奖励。

## 声音与动画

音效使用 22,050 Hz、单声道、16 bit PCM 原创短音，最长 0.60 秒；默认 AudioSource 音量建议 0.25。无背景音乐。错误使用低音双音，不用刺耳蜂鸣。清洁进度需限频，清洁完成使用阶段完成短乐句。重复完成回调不得重复播音，音效关闭后不得播音。

保留拾取 0.10 秒、吸附 0.15 秒、回弹 0.18 秒、污渍淡出 0.08 秒及结果面板约 0.24 秒。装饰 tween 必须被持有者停止，复用节点先清理完成态，不能改变计数时点或输入锁。
